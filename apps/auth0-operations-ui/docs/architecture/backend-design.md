# Backend design — blocked at identity gate

No listener, routes, middleware, connected adapter, or customer-data service is implemented. `backend/design/contracts.ts` is non-executable design only: a real boundary must authenticate and obtain current organization permissions independently before each operation. A typed principal is not proof. Failure, unavailable identity authority or stale membership must deny. An org selector narrows scope but never grants it. Do not read or log bearer tokens, ticket contents or raw Auth0 logs in general logs.

Candidate service: a small Node service and relational store, if platform delegation is approved. Request lifecycle: TLS and request limit → verifier → current membership/permission lookup → runtime validation → organization-scoped database transaction → sanitized audit event → structured response. Revalidate access at commit or obtain a platform-provided consistency guarantee; otherwise explicitly bound the revocation race. Uniform 404 for inaccessible or absent records, 401 for authentication, 409 for version conflicts; avoid account enumeration. Time out requests without assuming remote cancellation. Do not automatically repeat an investigation with unknown outcome. Mutating creation needs scoped idempotency keys and stored request hashes in the same transaction; retention must be specified. An authenticated health/readiness endpoint should not disclose secrets; liveness can be minimal.

Candidate endpoints are `GET/POST /tickets`, `GET/PATCH /tickets/:id`, `GET/POST /tickets/:id/investigations`, and `GET /investigations/:id`. They are not implemented. Listing needs bounded pagination; updates use expected versions; investigation creation atomically binds its ticket. Evidence read requires its own permission and authorized parent chain. Draft storage, delete and archival are deferred. Validate fields and reject unexpected input. Restrict egress, redact logs and handle shutdown by stopping new work and draining transactions. No credentials belong in React. A future connected UI must expose auth, loading and network errors without switching to fictional records.
